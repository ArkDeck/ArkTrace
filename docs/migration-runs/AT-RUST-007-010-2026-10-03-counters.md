共享 StoreReader 与 NoCacheSession 已提供 typed `counters`、独立 `counter_series` 和 Agent
counter 页；实际 Rust CLI 增加 `query --view counters`。样本值、timestamp、duration、filter ID
和物理行身份均保留 Int64；没有浮点数转换。事件身份包含 `measure` 或 `process_measure`，
支持 process counters 的兼容 `measure` 来源。每个物理来源独立取 limit+1，再按 timestamp、
table、rowid、scope source、filter ID 合并到全局样本预算；series 目录按 scope/filter ID 枚举，
避免热门 series 的样本挤掉其它时间线 lane。样本页的 group 顺序保持 scope/scope ID/filter ID。

NULL/负 INTEGER duration 为 open-ended；无 duration 列及不兼容的可选 duration 保留 instant，
后者记录 dropped-value。正 duration 使用完整 Trace 的夹取区间，不截成查询窗口。名称
exact/prefix/contains 转义 LIKE；filter ID 支持 0、负数和完整 Int64。CPU scope 与 process/PID
scope 互斥。CLI 拒绝 thread/state/depth/min-duration 等不适用 filters。Machine 1.0 保留完整
request、nested result filters、单一 counters 数组、9-field event 和 4-field sample、显式 null、
quality、truncation、provenance。SDK series descriptor 保持 Swift synthesized Codable 的可选
字段省略规则。bounded encode 和显式 close 成功后才输出，human 使用既有 terminal escaping。

样本查询预先核对所有来源的未遮蔽 rowid alias。WITHOUT ROWID 或三个 alias 全被用户列
遮蔽时返回闭合 `TRACE_SCHEMA_UNSUPPORTED/querying`，details 为
`counterSampleIdentity` 和物理 table；series 目录仍可查询。可选 unit/PID/name 的异常不丢掉
样本，并按物理表归因；缺失 process 引用使用 `process_measure_filter.ipid`。重复的物理事件
身份与不可解码的必需名称失败为 `QUERY_FAILED`，不伪造 rowid 或替补未选中的样本。
