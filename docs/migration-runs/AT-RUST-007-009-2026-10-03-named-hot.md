## 查询实现

`TraceSliceQuery`、`TraceSlice` 接入已有单 worker readonly StoreReader 和 NoCacheSession。
不新增裸 SQL API；复用 CPU/state 的时间归一化、质量、参数绑定、取消和 retained descriptor。
raw page 保持 source ts/id 的 limit+1，掉落的无效行不补位；Agent page 按归一化时间/id 排序，
合并整体 Trace quality。能力不可用仍区别于支持但空结果，Agent 在能力检查前验证范围。

- Machine DTO 的 **14 个字段**保留明确 null、Int64、table-qualified key、instant/open-ended。
  argument-set handle 只在 SDK 请求时读取，编码时省略，解码恢复 nil。
- 名称 exact/prefix/contains 参数化；LIKE 的 `%`、`_`、反斜杠按字面转义。raw 空名称合法，
  Agent 请求空名称拒绝。required name ≤4096 UTF-8 bytes，category ≤1024；错误类型/无效
  UTF-8/可选字段的降级与质量计数保持 Swift 语义。
- 最小时长比较**完整 Trace 归一化区间**，不按请求窗口截短。Int64 极值、pre-trace、
  NULL/negative duration、instant、exclusive end 都有回归。
- 缺 depth 时返回 `TRACE_SCHEMA_UNSUPPORTED/querying` 和闭集
  `missingCapability=namedSliceDepth`。parent 0/负数/4294967295 为 absent，非零 cookie 为 async，
  depth 的负数源值保留；argument handle 的 0/负数整数不套 parent 哨兵。
- 缺失 thread reference 与 0/NULL 身份区分；坏 argument storage 不伪造 handle 或新增 quality。

## 实际热点接入

`analyze_bounded` 用同一四个身份 filters、minimumLongSliceDurationNs 和独立 maximumHotEvents
查询 named page。向 pure reducer 传递实际 callstack key/full range、quality、capability 和
truncation；投影每 256 条检查 token/deadline，结束后再次验证数据库、metadata、lease。
pure reducer 拒绝其他 table 的 named identity。CPU 与 named 的热点预算分别保持，未读取 args。

本入口仍有六个 section，调度延迟的固定 parser Runnable semantics **仍为 Unproven**。
没有使用 normalized enum 或调用者输入替代 upstream attestation。产品 long-slice reduction、
七-section priority/full envelope、summary/context 和 CLI/SDK/App 接通仍待完成。
