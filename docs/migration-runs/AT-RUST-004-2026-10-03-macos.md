## 实现与保持的边界

- `arktrace-platform` 持有 Darwin file/directory descriptor，沿祖先逐级 no-follow 打开并复核
  device/inode、类型、路径绑定。显式原始输入只解析一次链接，内部文件、工具、lease 拒绝链接。
- 私有资源检查 owner、mode、ACL、mount ownership enforcement，不修已有用户权限。
  空 ACL/deny-only ACL 可接受；额外 allow grant 拒绝。`0700` mode 不能覆盖 ACL 的额外授权。
  ACL FFI 声明按当前 Xcode SDK `sys/acl.h` 核对；分配与释放、返回值遵循
  [Apple ACL descriptor 文档](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/acl_get_fd_np.3.html) 和
  [Apple ACL entry 文档](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/acl_get_entry.3.html)。
- 原始输入分块读取、hash 与整文件快照复制受字节、deadline、cancel 预算约束；原始 bytes 不变。
  新快照封为 `0400`（工具快照 `0500`），关闭 writable FD 后对 exact output 独立校验 hash。
- 新文件以 `RENAME_EXCL` 在同卷无覆盖发布；发布前在取消临界区再次核对路径绑定。
  发布后除 rename 的合法 ctime 变化外，候选的 metadata 必须仍一致。同 inode/大小的原位改写也拒绝。
  取消后的回滚仅移除能证明 identity 的结果；清理失败优先于取消，保留不相关 replacement。
- `flock` lease 与既有文件协议一致。17 个 cache/lease 向量在 Swift 和 Rust 中执行：
  length-prefixed parser key、entry identifier、lock/lease 路径、UTF-8 边界与 Int64 上界。
  Windows 锁偏移冻结为十进制 `18446744073709551614`，长度 1；尚未做 Windows native admission。
- 非 platform 一方代码 forbid unsafe；platform 除 macOS syscall 模块外 deny unsafe。
  Cargo freeze 增加 SHA-256/syscall 所需依赖，21 个三方版本、license expression 与原文 hash 已核对。

这提供文件级发布原语；Engine 的 Ready DB 还需要 parser、schema/index、完整 owner 目录与 Session
协议，当前不声称 Rust Engine 已能打开 Trace。Swift 产品仍在使用现有实现。
